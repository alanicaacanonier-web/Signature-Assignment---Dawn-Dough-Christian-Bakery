# Signature-Assignment---Dawn-Dough-Christian-Bakery
Dawn & Dough is a multi-page bakery website created for ITC2400, designed to reflect a faith-centered experience centered on community, connection, and food. The site features an interactive menu with category filtering and image modals, an order and delivery system with real-time calculations and form validation, interactive support services, slideshows for community engagement, and a testimonial system with star ratings. Built using HTML, CSS, and JavaScript, the project emphasizes responsive design, accessibility, and a clean user experience. Images are sourced from Unsplash, along with custom-generated icons and graphics used for educational purposes.
